# FajnSlovní druhy

Hra na procvičování určování slovních druhů pro FajnCvičebnu (fajndoucko.cz).
Zadání a pravidla projektu: `CLAUDE.md`. Datový formát: `docs/format-dat.md`.

Demo: https://pelunkaj-dot.github.io/fajn-slovni-druhy/demo.html

`demo.html` používá stejné herní moduly a vzhled jako plná aplikace.
Obsah je v `data/demo.json`: 3 obtížnosti po 4 schválených větách; slovní režimy čerpají pouze schválená samostatná slova z těchto vět.
Demo neukládá dlouhodobý postup, ignoruje `mode=full` a místo rodičovských statistik ukazuje informace o plné verzi.
